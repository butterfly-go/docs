# S3 object storage

## Configuration

```yaml
store:
  s3:
    assets:
      endpoint: "s3.amazonaws.com"
      region: "us-east-1"                        # default: us-east-1
      bucket: "my-assets"
      access_key_id: "AKIAIOSFODNN7EXAMPLE"      # or "ak"
      secret_access_key: "wJalrXUtnFEMI/K7MDENG" # or "sk"
      use_ssl: true
      use_path_style: false                      # true for MinIO and similar
```

The key (`cache`, `main`, ...) is the name you pass to the getter. See [Data stores](/stores/overview) for behavior shared by all stores, and the [configuration reference](/guide/configuration#core-configuration-reference) for every option.

## Usage

AWS S3 and compatible services such as MinIO work. See the [configuration reference](/guide/configuration#core-configuration-reference) for the options. The short forms `ak` and `sk` are accepted for `access_key_id` and `secret_access_key`, and MinIO needs `use_path_style: true`.

```go
import (
    "context"
    "io"

    "butterfly.orx.me/core/store/s3"
    awss3 "github.com/aws/aws-sdk-go-v2/service/s3"
)

func uploadFile(ctx context.Context, key string, body io.Reader) error {
    // "assets" is store.s3.assets in the configuration file.
    client := s3.GetClient("assets")
    bucket := s3.GetBucket("assets")

    _, err := client.PutObject(ctx, &awss3.PutObjectInput{
        Bucket: &bucket,
        Key:    &key,
        Body:   body,
    })
    return err
}
```
